# Math Fun

Small, silly, encouraging math games for a young learner, played on an iPad as a Home Screen web app.

**Play:** https://joeattardi.github.io/math-fun/

Games so far:

- **Greater or Less?** Compare two numbers using a number line. Hops the Frog jumps by tens, then ones, so "farther along means greater" is something you can see.

Built with Vite, TypeScript, Phaser 4, and Tone.js. All art and audio are generated by code. See [CLAUDE.md](CLAUDE.md) for the design principles and constraints.

## Run it

```sh
npm install
npm run dev       # dev server at http://localhost:5173/math-fun/
npm test          # unit tests (question generation, adaptivity, progress, vocabulary)
npm run build     # typecheck + production build into dist/
npm run preview   # serve the production build
npm run lint
```

## Test on the iPad over your LAN

1. Run `npm run dev` on a computer on the same Wi-Fi as the iPad. Vite prints a `Network:` URL such as `http://192.168.1.20:5173/math-fun/`.
2. Open that URL in Safari on the iPad, in landscape.
3. Tap **Tap to Play** to turn on sound and voices. iOS blocks audio until the first tap.

The dev server doesn't register the service worker, so you can't "install" it this way. Use the deployed site for that.

## Install on the iPad

1. Open https://joeattardi.github.io/math-fun/ in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Launch it from the new icon. It runs full screen and works offline.
4. New versions download automatically. Close and reopen the app to get them.

Grown-up stats: on the main menu, press and hold the **Math Fun!** title for 3 seconds.

## Add a new game

1. Create `src/games/<game-id>/` with an `index.ts` that exports a `GameDefinition` (see `src/games/types.ts`). It needs an id, title, tile color, icon drawing function, entry scene key, and scene classes.
2. Add it to the list in `src/games/registry.ts`. The menu tile and scene registration happen automatically.
3. Build on `src/shared/`: audio (`music`, `sfx`, `speech`), characters (Chomp, Waddles, Hops), UI (`Button`, `SpeechBubble`, `NumberLine`, `ComboMeter`, effects), `progress`, and `praise`. Extend shared code instead of copying it, and never import from another game.
4. Keep game logic in plain TypeScript modules with tests in `tests/`. Keep line banks in data files.

## Debug hooks

Add `?debug=1` to the URL to expose game state on `window.__mathFun`. Add `&fast=1` to speed up animations and `&seed=123` to make questions repeatable. The automated playtests use these.

## Deploying

Every push to `main` runs `.github/workflows/deploy.yml`, which tests, builds, and publishes to GitHub Pages. In the repo settings, Pages must be set to **Source: GitHub Actions**.
